# Aidora - تطبيق إدارة العلاقة الإنسانية

## نظرة عامة

Aidora هو تطبيق Flutter مصمم لإدارة العلاقة بين النازحين والمنظمات الإنسانية. يوفر التطبيق منصة سهلة الاستخدام لربط الأشخاص المحتاجين بالمنظمات التي يمكنها مساعدتهم.

## المميزات الرئيسية

### 1. شاشات الترحيب (Onboarding)
- شاشة البداية مع شعار Aidora
- ثلاث شاشات تعريفية توضح فوائد التطبيق
- انتقال تلقائي بين الشاشات كل 3 ثوانٍ
- تصميم جذاب مع رسوم توضيحية مخصصة

### 2. المنظمات المدعومة
- UNICEF - حماية الأطفال والتعليم
- INTERSOS - الاستجابة للطوارئ
- WFP - برنامج الغذاء العالمي
- UNHCR - المفوضية السامية للاجئين
- WHO - منظمة الصحة العالمية
- الهلال الأحمر - المساعدات الطارئة

### 3. الوظائف الأساسية
- تصفح المنظمات كضيف
- تسجيل الدخول/إنشاء حساب مع Validation كامل
- عرض تفاصيل كل منظمة
- طلب المساعدة
- التطوع مع المنظمات
- **صفحة طلباتي (My Requests)** - عرض وإدارة جميع الطلبات

### 4. صفحة الطلبات (جديد!)
- **إحصائيات ديناميكية**: عرض إجمالي الطلبات، المقبولة، والمرفوضة
- **الطلبات المقبولة**: 
  - معلومات التفاصيل والاستلام
  - رمز QR للاستلام
  - حالة الطلب
- **الطلبات المرفوضة**: عرض سبب الرفض
- **تحديثات فورية**: آخر الأخبار والتحديثات
- **Pull to Refresh**: تحديث البيانات بسحب الشاشة للأسفل
- **التكامل مع API**: جاهز للربط مع Backend

## التقنيات المستخدمة

- **Flutter** - إطار عمل تطوير تطبيقات الموبايل
- **GetX** - إدارة الحالة والتنقل
- **Google Fonts** - الخطوط المخصصة
- **Custom Painters** - الرسومات التوضيحية المخصصة
- **HTTP Package** - للاتصال بالـ API

1. **استنساخ المشروع**

3. **تشغيل التطبيق**

## سير عمل التطبيق

1. **شاشة البداية (Splash Screen)**
   - عرض شعار Aidora
   - الانتقال التلقائي بعد 3 ثوانٍ

2. **شاشات التعريف (Onboarding)**
   - الشاشة 1: "الدعم الذي يصلك أينما كنت"
   - الشاشة 2: "المتطوعون والمنظمات العاملة لدعمك"
   - الشاشة 3: "شكراً لاهتمامك بالمساعدة"
   - انتقال تلقائي كل 3 ثوانٍ

3. **شاشة الترحيب (Welcome)**
   - خياران: منظمة أو الاستمرار كضيف
   - إمكانية تسجيل الدخول

4. **قائمة المنظمات**
   - عرض جميع المنظمات الداعمة
   - شريط بحث بالاحتياجات
   - أزرار طلب المساعدة والتطوع

5. **تفاصيل المنظمة**
   - معلومات عن المهمة
   - الفئات المستهدفة
   - الخدمات المقدمة
   - صور التأثير
   - روابط التواصل

6. **تسجيل الدخول/إنشاء حساب**
   - **Validation كامل على جميع الحقول**:
     - الاسم: لا يقل عن 3 أحرف، حروف فقط
     - الهاتف: 10 أرقام على الأقل
     - البريد الإلكتروني: تنسيق صحيح
     - كلمة المرور: 8 أحرف، حروف كبيرة وصغيرة وأرقام
     - العمر: بين 18-120 سنة
     - الجنس: إلزامي
     - الموافقة: إلزامية
   - تسجيل دخول بـ Google
   - إنشاء حساب جديد

7. **صفحة طلباتي (My Requests)** 🆕
   - عرض الإحصائيات الديناميكية
   - قائمة الطلبات المقبولة والمرفوضة
   - إمكانية إضافة طلب جديد
   - تحديثات فورية
   - شريط تنقل سفلي

## ربط التطبيق مع API

راجع ملف `API_INTEGRATION_GUIDE.md` للحصول على دليل كامل لربط التطبيق مع الـ Backend API.

### نقاط الـ API المطلوبة:
- `GET /api/requests` - جلب طلبات المستخدم
- `POST /api/login` - تسجيل دخول
- `POST /api/signup` - إنشاء حساب
- `POST /api/requests` - إنشاء طلب جديد

### مثال على الاستخدام:
```dart
// في RequestsController
await fetchRequestsFromAPI();
```

## Validation Rules

### الحقول المطلوبة:
1. **Full Name**:
   - الحد الأدنى: 3 أحرف
   - أحرف إنجليزية فقط
   
2. **Phone**:
   - الحد الأدنى: 10 أرقام
   - يمكن أن يحتوي على: أرقام، +، -، ()، مسافات
   
3. **Email**:
   - تنسيق بريد إلكتروني صحيح
   - مثال: user@example.com
   
4. **Password**:
   - الحد الأدنى: 8 أحرف
   - يجب أن يحتوي على: حرف كبير، حرف صغير، رقم
   
5. **Age**:
   - بين 18 و 120 سنة
   - أرقام فقط
   
6. **Gender**:
   - اختيار إلزامي
   
7. **Consent**:
   - يجب الموافقة للمتابعة
